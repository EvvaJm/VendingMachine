C Vending Machine

**Description**
This is a simple vending machine program. The program allows a user to select a snack/drink, pay for it using Canadian coins and calculates their change. 

**Features**
- Displays a menu with 4 products
- Validates the user's selection
- Accepts Canadian coins (5,10,25,1,2)
- Validates coin input
- Tracks the total amount inserted
- Calculates the user's change

**How it works**
The program first asks the user to make a drink/snack selection by inputting a number. It then determines the cost of the item and asks the user to enter Canadian coins. It keeps track of the total of the coins entered, and once the total is equal to or greater than the price, it calculates the change if needed. It then displays the total change (if calculated) and a message to "Enjoy your snack :)".
